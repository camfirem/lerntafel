# Contributing

Thanks for your interest in Lerntafel.

## Source code

This repository holds documentation and release downloads only — there is no source code here to contribute to. See [README.md](README.md) for what Lerntafel is and how to get it.

## Pull requests

**Pull requests are not accepted at this time.** Lerntafel is closed-source and Mark Friedrichs remains the sole owner of the project; this keeps ownership and licensing unambiguous. This may change in the future.

## How you can help

- **Bug reports and feature ideas:** [open an issue](../../issues/new/choose). Include your Windows version, the Lerntafel version, and steps to reproduce if it's a bug.
- **Security issues:** please follow [SECURITY.md](SECURITY.md) instead of a public issue.
- **General feedback:** also welcome via issues — what works, what doesn't, what's missing.
